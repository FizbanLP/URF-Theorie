# plots/

Dieses Verzeichnis enthält die Abbildungen, die vom Jupyter Notebook erzeugt werden.

Führe `code/URF_SPARC_Analysis.ipynb` aus, um alle Plots zu generieren:

- `urf_rotation_curves.png`   — Rotationskurven-Fits (6 SPARC-Galaxien)
- `urf_eta_universality.png`  — eta-Universalität (171 Galaxien)
- `urf_ngc3198_fit.png`       — NGC 3198 Detailfit mit chi²-Analyse
- `urf_baryonic_fraction.png` — Universeller baryonischer Anteil
